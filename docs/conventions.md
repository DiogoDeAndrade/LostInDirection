# Conventions

## Code

Match UnityCommon and the other GCC projects:

- Allman braces, 4-space indentation.
- Game scripts in the global namespace; `using UC;` for UnityCommon.
- Inspector fields `[SerializeField] private`, camelCase, with types and names column-aligned:

  ```csharp
  [SerializeField] private Player     playerPrefab;
  [SerializeField] private SoundDef   gameOverSound;
  [SerializeField] private float      respawnTime = 5.0f;

  CooldownTimer   playerRespawn = new();
  Vector3         respawnPosition;
  ```

- Private runtime fields: no access modifier, no prefix. Underscore only for a serialized backing field exposed by
  a property (`[SerializeField] private bool _needLight;` / `public bool needLight => _needLight;`).
- Animator parameter hashes cached as `static int xID = Animator.StringToHash("X");`.
- Conditions often fully parenthesised: `if ((!prevState) && (state))`.
- NaughtyAttributes for inspector polish (`[Button]`, `[ShowIf]`, `[Expandable]`, ...).
- Reuse UnityCommon types (`Singleton<T>`, `SoundDef`, `Hypertag`, `CooldownTimer`, ...) before writing new ones.

## Root README

Same structure as the other GCC projects (Shroomjumper is the reference):

1. `# TITLE` in uppercase, then `Developed for the October'2026 [Game Creator's Club] at Lusofona University.` and
   `This month, the theme is "Lost In Translation".`
2. `## Game` - what the game is and how it plays.
3. `## Todo` - checklist (`- [ ]` / `- [x]`), ticked as things get done.
4. `## Art`, `## Sound` - one bullet per third-party asset:
   `[Asset name](url) by [Author](author url), licensed through the [CC0] license.` (or `[CC-BY 4.0]`, ...).
   Generated content is credited too (e.g. "Music by [Suno]", "Some of the pixel art generated by ChatGPT").
   Each list ends with `Everything else done by [Diogo de Andrade], licensed through the [CC0] license.`
5. `## Code` - `Uses [Unity Common], [MIT] license.`, NaughtyAttributes and any other code dependency with its
   license, `AI assistance was used in this game (Claude Code).`, then
   `All remaining game source code by Diogo de Andrade is licensed under the [MIT] license.`
6. `## Metadata` - `- Autor: [Diogo de Andrade]`.
7. Reference-style link definitions at the bottom (license links, authors, tools, `[MIT]:LICENSE`).

Add the credit line in the same commit that brings in a third-party asset.

## Releases

With the first build, add `RELEASES.md` at the root, newest entry first:

```
# V1.0.0 (dd/mm/yyyy)

- Initial release, for the October Game Creators Club (theme "Lost In Translation")
```

## Commits

- Plain English, one line describing what changed; several related changes in one commit are joined with
  semicolons (see `git log` here or in the other GCC repos).
- Never mention Claude or AI in commit messages: no `Co-Authored-By` trailer, no "Generated with ..." footer.
